# Fig.2 public data

This folder contains deidentified processed datasets prepared for public release and figure reproduction for Fig.2.

## Included files
- `fig2a_average_spectra_carotenoidHigh_vs_Low.csv`: long-format average spectra for carotenoid-low vs carotenoid-high cells after RBC-like cluster exclusion.
- `fig2b_regionwise_carotenoidHigh_fraction.csv`: region-level carotenoid-high fractions and confidence intervals for Fig.2B.
- `fig2c_bridge_plot_data.csv`: deidentified case-by-region summary table used for the bridge plot in Fig.2C.
- `fig2d_samecell_raman_if_public.csv`: deidentified same-cell Raman–IF table used for Fig.2D.
- `data_dictionary_fig2.csv`: column guide for the public Fig.2 package.

## Deidentification
Absolute dates and original identifiers are not included in this public package. Study-specific pseudonymous case IDs (`Case01`, `Case02`, ...) are used instead.

## Notes
These files are intended for figure reproduction and manuscript transparency. They do not include raw spectra, raw image files, original patient identifiers, or spatial coordinates.
