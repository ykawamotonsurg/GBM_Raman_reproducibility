# GBM Raman reproducibility

Processed data and Python scripts for reproducing figure panels from the GBM Raman spectroscopy study.

All panels below are generated by [main/code/plot_saved.py](main/code/plot_saved.py), using the listed CSV files.

## Run

Requires Python 3.12. Run from the repository root:

```sh
python -m pip install -r requirements.txt
python reproduce.py --scope main --out results_main
```

Main-figure PNGs are written to `results_main/main/numeric/`. Use a new or empty output directory.

## Data behind the summaries

| Figure | Additional input | Processing |
|---|---|---|
| 2B–D | [Score definition](shared/data/carotenoid_threshold.csv), [standardization coefficients](shared/data/global_peak_standardization.csv) and the existing per-cell table | Fixed scores, labels and coordinates |
| 3B | [Per-cell Raman–MSR1 labels](main/data/samecell_labels.csv) | Counts in Table S6 |
| 3C–D | [Culture measurement-unit means](main/data/culture_unit_means.csv) | All-condition summaries and the existing paired observations |
| 4B | [Program gene sets](shared/data/spatial_gene_sets.csv) | Definition of the reported spatial scores |

To reconstruct the cell counts and culture summaries:

```sh
python main/code/summarize_fixed_inputs.py --out checked_summaries
```

The command checks the results against the supplied tables and writes to a new directory. Missing MSR1 measurements remain unevaluable.

## Supplementary figures

Supplementary data and plotting scripts are in [supplement/](supplement/). The [figure-to-file index](metadata/figure_data_map.csv) lists the input data, script and output for every included panel.

```sh
python reproduce.py --scope supplement --out results_supplement
```

Supplementary PNGs are written to `results_supplement/supplement/numeric/`. Use `--scope all` to generate both groups in one run.

## Analysis methods

The [temporal evaluation files](supplement/analysis/s2b/README.md) provide the fixed S2B inputs, early OOF and late predictions, fold assignments, preprocessing parameters, native XGBoost model and method functions. Saved-model inference can be reproduced without training.

[Statistical method code](supplement/analysis/statistics/fixed_input_statistics.R) uses the supplied case-level tables for the single-cell trend, tissue–cell association and MRI analyses. Its [recorded environment](supplement/analysis/statistics/environment.json) is included. The MRI association and rater-agreement calculations have been run using the same supplied measured-volume input; the single-cell trend and tissue–cell association scopes have not been rerun for this package. Statistical analysis is separate from plotting.

To reproduce the MRI association statistics only (R 4.5.2; `readr` and `dplyr`):

```sh
Rscript supplement/analysis/statistics/fixed_input_statistics.R . results_mri mri
```

[MRI_CaseData.csv](supplement/data/MRI_CaseData.csv) is the shared input for MRI association and rater agreement. It contains both raters' total and necrotic volumes (mm³) and fixed CE high/total cell counts. Enhancing volume is `total - necrotic`; the association uses rater 1's enhancing fraction `(total - necrotic) / total`. The command verifies the stored fraction against these volumes and writes Spearman statistics and bootstrap intervals, the quasi-binomial model, the case-bootstrap OR interval, and leave-one-out results to a new directory.

To regenerate the saved rater-agreement tables for Fig. S7A (also requires `psych`, `lme4` and `tibble`; versions in the recorded environment):

```sh
Rscript supplement/analysis/statistics/mri_agreement.R . results_mri_agreement
```

This command uses the same case-level volumes to write Pearson and ICC(2,1) results and Bland–Altman plot tables. Both MRI analysis commands write to new directories; they do not overwrite the supplied plotting CSVs.

## Data scope

The scripts plot processed scores, coordinates, classifications and summary statistics supplied in the CSV files. They do not rerun model training, UMAP fitting or statistical tests. Microscopy images, schematics and final multi-panel layouts are outside this plotting package.

The [data guide](DATA.md) describes the analysis units, related supplementary tables and the scope of the supplied inputs. Column descriptions are in [data_dictionary.csv](metadata/data_dictionary.csv). Package versions are recorded in [requirements.txt](requirements.txt) and [environment.json](environment.json).

The original `v1.0.0` release is archived at [10.5281/zenodo.19363426](https://doi.org/10.5281/zenodo.19363426). That DOI identifies the original archive. It does not identify later changes to this repository.
